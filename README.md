# Laboratorio UCV - Perceptrón Simple

## Objetivo

Implementar desde cero un perceptrón simple para resolver
un problema de aprobación de créditos.

## Caso de negocio

Un banco desea automatizar la aprobación preliminar de
créditos utilizando el ingreso mensual y el historial crediticio.

## Tecnologías

- Python 3.12
- Git
- GitHub
- GitHub Actions
- pytest
- SonarCloud

## Estructura

- src/dataset.py: datos de entrenamiento.
- src/perceptron.py: implementación del perceptrón.
- tests/test_perceptron.py: pruebas automáticas.
- main.py: ejecución del modelo.
